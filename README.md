# SteelTouch G-код: веб-версия

Калькулятор фасок, скруглений и сфер из Android-приложения, переписанный на HTML, CSS и JS для iPhone и любых браузеров.
Сборка не нужна: это обычные статические файлы.

- `js/gcode.js` — расчёт, перенос `core/gcode` один в один (те же кадры, проверки и предупреждения).
- `js/plot.js` — схема с анимацией пластины, перенос `ToolpathPlot`.
- `js/app.js` — экран, перенос `GcodeScreen.kt`.
- `test/gcode.test.js` — ожидаемые значения из Kotlin-тестов.

## Проверка

```bash
node --test web/test/gcode.test.js
```

Локально: `python -m http.server 8765 --directory web`, затем http://localhost:8765.

## Публикация на GitHub Pages

Положите содержимое папки `web` в корень репозитория (или в папку `docs`), затем
Settings → Pages → Deploy from a branch → `main` и `/ (root)` (или `/docs`).

## На iPhone

Откройте ссылку в Safari → «Поделиться» → «На экран Домой». Калькулятор откроется как приложение
и после первого открытия будет работать без интернета.

Цифровая клавиатура iPhone без минуса, поэтому у полей Z есть кнопка «±».

## Фреза: отвод по Y

Только в веб-версии, в Android-приложении этого режима пока нет. Поперечная приводная фреза опускается по X;
её центр должен стоять от оси детали не ближе чем на полуширину заготовки на уровне торца фрезы
(√(R² − h²), а до оси — весь R), плюс радиус фрезы и зазор. Переключатель «Y на диаметр / на радиус»
удваивает значение для программы; какой режим стоит на станке, нужно проверить пробным ходом.
